## ساخت APK با GitHub Actions

1. محتویات پوشه `AnbarApp` را در **ریشه** ریپو قرار دهید (نه داخل زیرپوشه اضافه).
2. Push روی `main`.
3. از تب **Actions** آرتیفکت `app-debug` را دانلود کنید.

دستور محلی:
```bash
chmod +x gradlew
./gradlew :app:assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`
